## Purpose

This document is the shared memory of the project.

It records the principles and architectural decisions that define the website.

New entries are added only when they change how the website is conceived or built.

---

## Vision

A static studio website presenting my image-making practice through film, photography and writing.

The website is not a portfolio.

It is a studio: an architectural space that visitors enter to encounter a way of seeing, thinking and making.

Visitors move through rooms rather than pages.

The website should feel edited rather than assembled.

---

## Design Language

The website should feel:

- cinematic
- generous
- confident
- materially simple
- warm
- never decorative

The interface recedes behind the work.

Motion should feel alive, never flashy.

Editing always takes precedence over decoration.

Materiality takes precedence over interface.

The website may become visually dense when the work requires density. Density should come from the accumulation and relationship of materials, not from decorative interface elements.

---

## Principles

- Static website.
- HTML and CSS first.
- Minimal interface.
- Fast loading.
- One stylesheet.
- Reuse before creating.
- Lowercase naming throughout.
- HTML describes structure.
- CSS describes appearance.
- The interface should disappear behind the work.
- The website is edited like a film.
- Every modification should strengthen the sequence.
- Work should determine the interface, not the other way around.
- Do not add interface elements merely to fill space.

## The Image Room

The Image Room is a composed visual score rather than a gallery.

It is primarily a moving-image room, but moving and still images have equal editorial status.

Projects are movements within that score.

Each movement occupies one horizontal band and establishes its own rhythm, density and colour palette.

A band may contain:

- moving image
- still image
- text
- colour
- sketches
- process material
- fragments of research
- other material generated by the work

The composition is fixed.

The browser frames the score but never composes it.

Desktop is the master composition.

Mobile is a re-edit of the same score rather than a scaled copy.

The Image Room should feel like a field of works, not a collection of thumbnails.

---

## Project Bands

Every project band is an independent composition.

Each band has its own:

- rhythm
- scale
- spacing
- density
- colour atmosphere

Colour belongs to the project rather than individual tiles.

Project titles belong to the project band.

Every tile has an intentional position.

The position of an element is editorial.

---

## Work Spaces

A project may open from the Image Room into a dedicated work space.

The work space is not a conventional project page or portfolio case study.

It is an extension of the work.

A work space may contain:

- a large moving image
- selected film fragments
- still images
- text
- credits
- research material
- process material
- drawings or diagrams
- other material appropriate to the work

The amount and density of material should be determined by the work.

A work space should not automatically become cleaner or more minimal than the work itself.

Navigation should remain quiet and secondary.

A dedicated work space may contain several fragments of the same work, allowing the visitor to move between them without repeatedly returning to the Image Room.

---

## Moving Image

Moving image is treated as a first-class material of the studio.

Short films, fragments, tests and moving-image works may appear directly within the Image Room or within dedicated work spaces.

The website does not host production masters.

Video delivery is handled externally through Bunny.

The website references the delivered video rather than becoming responsible for video storage or transcoding.

Canonical web video formats remain:

### Landscape

1920 × 1080 px (16:9)

### Square

1080 × 1080 px

Production masters remain separate from web delivery files.

## Editorial Density

The website should not confuse minimalism with emptiness.

Whitespace is structural.

Density is also structural.

A page may become dense when the accumulation of images, moving image, text, research or other material is part of the work.

The goal is not to make every page equally clean.

The goal is to create the appropriate rhythm between empty space and material.

The interface should remain simple even when the work becomes dense.

## Collaboration

When generating code:

- Read this guide first.
- Respect the existing architecture.
- Implement before redesigning.
- HTML first.
- CSS only when requested.
- Never duplicate CSS.
- Reuse existing classes whenever possible.
- Preserve existing visual decisions unless there is a clear architectural reason to change them.

Every design decision should strengthen the sequence rather than add complexity.
